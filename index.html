《小狐的心情故事》

角色视觉设计与交互规范手册 (v1.0)

文档目的与定位

本手册旨在为《小狐的心情故事》（3-6岁儿童情绪教育AI产品）提供统一的视觉规范与交互设计基准。重点针对核心IP“小狐”进行极简低饱和二维卡通风格的形象定位，以便后续进行UI设计、Figma组件库搭建及Web Demo开发。

核心理念

情绪可以出现，但行为需要选择。

设计原则

少文字、大角色、强视觉引导；陪伴式体验，避免强说教。
一、小狐（Little Fox）造型规范

1. 基础造型比例

  • 头身比例：1:1.5 至 1:2 大头小身体，增强幼态感与安全感。
  • 线条风格：全圆角设计，无尖锐棱角；采用极浅手绘线条或无描边扁平风格。
  • 服饰特征：穿戴极简鼠尾草绿小背心，增加生活亲和感。

2. 面部与姿态规范

  • 眼睛：大圆眼带浅白高光，表情温和有神。
  • 耳鼻：耳朵呈圆润三角状，内耳粉色；小巧黑圆鼻子。
  • 姿态：常态呈双手微伸、身体微前倾的“倾听与拥抱”姿态。

三、AI 情绪与行为状态表达

1. 倾听/等待状态 (Idle)

表情：眼睛微睁大，头部微微偏向一侧。
动作：双手叠于胸前，微弱呼吸起伏。
场景：孩子语音或点击回答时。

2. 共情/鼓励状态 (Empathetic)

表情：眼弯成月牙状 (^^)，腮红加深。
动作：单手抚胸，身体微前倾。
场景：孩子成功识别情绪时给予正面反馈。

3. 思考/引导状态 (Thinking)

表情：单眼微向上看，嘴巴呈微“O”型。
动作：食指抵下巴或指向上方画面。
场景：引导思考“小熊现在该怎么办？”。

4. 表达/讲述状态 (Speaking)

表情：嘴巴带有2-3帧开关口型。
动作：双手作小幅度展开姿态。
场景：AI小狐播报语音引导词。

四、首页 UI 重构布局规范
  • 背景场景：极简二维森林一角，浅黄绿草丘，远景扁平化树木与微弱日光斑点。
  • 角色居中：小狐坐于草地中央，占屏幕高度 45%-50%，强视觉焦点。
  • 文字压减：顶部仅保留标题“小狐的心情故事”（色值 `#4A3E3D`），小狐头顶带气泡：“你好，我是小狐！”。
  • 交互入口：底部采用单一大按钮“开始故事”（圆角胶囊状，浅珊瑚粉 `#E78B75`，带有轻微呼吸浮动动效）。
